# linkjs 是什么？ 

linkjs 是一个基于事件模块的微前端框架，可以实现微应用之间的通信和动态加载。


# 如何暴露模块？

通过 `exposeLib` 函数暴露模块，第一个参数为模块名称，第二个参数为模块实例，第三个参数为模块选项。
`exposeLib` 内部获取全局`eventBus`，将模块名称、模块实例、模块选项通过 `LIB_EXPOSE` 事件触发。

# 如何加载模块？

通过 `loadRemote` 函数加载模块，第一个参数为模块URL，第二个参数为模块选项。
`loadRemote` 内部获取全局`eventBus`，将模块名称、模块实例、模块选项通过 `LIB_READY` 事件触发。

1. 主工程启动的过程中会，会根据 loadRemote的子模块地址，加载子模块的HTML文件
2. 通过解析子模块的HTML文件，获取子模块的Js、css资源地址，并将子模块的Js、css 资源地址合并到主工程的Js、css资源地址中，这样就是实现了主工程加载的时候加载子工程了
3. 子工程加载的时候，会触发 `exposeLib` 事件，主工程监听到 `exposeLib` 事件后，会认为主工程加载完成，并将exposeLib中的入参返回给loadRemote 函数

从而实现了主工程动态加载子工程
